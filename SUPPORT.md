# Support

Use [GitHub Issues](https://github.com/azakapro/alifbo/issues) for reproducible bugs and verified transliteration-rule proposals. The structured issue forms ask for the information needed to investigate these reports.

For usage questions, first check the README examples and API descriptions. If they do not answer the question, open a discussion if GitHub Discussions is enabled, or use a clearly labelled question issue.

Do not submit private documents, personal data, credentials, or unpublished text in an issue. Reduce the problem to the smallest safe example.
