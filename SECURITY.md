# Security policy

## Supported versions

Until `alifbo` reaches 1.0, security fixes are provided for the latest published version only.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue. Use [GitHub's private vulnerability reporting form](https://github.com/azakapro/alifbo/security/advisories/new). If that form is unavailable, contact the maintainer privately through the contact information on the [maintainer's GitHub profile](https://github.com/azakapro).

Include the affected version, a minimal reproduction, the likely impact, and any suggested remediation. Avoid including real private Uzbek-language documents or credentials. You should receive an acknowledgement within seven days.
